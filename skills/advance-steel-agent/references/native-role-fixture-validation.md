# Native Role fixture validation

- Distinguish ModelRole.Key from ModelRole.RunName before a setter test. Read the existing AstorBase catalog without attaching or changing databases: the AS2027 USA/GBR catalogs map display `Beam` to key `Horizontal_Beam`, not key `Beam`. Verify the active catalog and setter semantics independently; a catalog match does not prove runtime persistence. Do not silently replace an explicitly authorized literal value with a different key.

- For the catalog-resolved Beam fixture, use `Role="Horizontal_Beam"` and verify Role/PureRole read back the key while RoleDescription reads `Beam`; require native identity/marks/material/hole-count invariance and save/close/reopen before IFC metadata acceptance. Preserve the failed display-name setter evidence rather than rewriting it as success.
- After closing and reopening a document, create a fresh shared AcadSession for final snapshot: an earlier session can retain a disconnected document COM wrapper. Do not reinterpret stale-wrapper errors as source corruption or bypass final idle/DBMOD gates.
- Treat a reflected public `AtomicElement.Role` setter as API availability, not proof a value was applied. Read Role/PureRole/RoleDescription on the same instance immediately, then through a fresh native read scope, and finally after save/close/reopen. If the value remains unchanged, do not save or claim success; investigate role value lookup and native document/write context without silently changing the requested value.
- Use the `bridge_model`/`update_object` job contract for an explicitly authorized isolated role mutation; `export_native_marks` is read-only and correctly rejects apply=true. Keep the execution entrypoint registered and dry-run by default.
- Hash an AutoCAD-open writable DWG in C# with a read-only FileStream that allows FileShare.ReadWrite; File.ReadAllBytes can fail on the legitimate writer share lock. Verify the baseline before opening as well, and never treat a read failure as permission to skip the hash gate.
- Bind mutation permission to the exact full-copy path, source hash, native ASId/handle, original marks and requested Role. Preserve baseline and failed-attempt evidence. Compare all other native objects, do not renumber, and never broaden permission to a production model.
- Keep rejected IFC-family schema output separate from role mapping acceptance: native Footing conversion can lack mandatory IfcFooting.PredefinedType. Reject publication rather than inventing a footing classification or calling nonempty role export passed.
